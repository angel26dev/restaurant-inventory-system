# Restaurant Inventory System 🍽️

Sistema de gestión de inventario diseñado para restaurantes y cocinas profesionales.

## Objetivo

Crear una herramienta sencilla para controlar productos, cantidades y alertas de inventario.

## Funcionalidades

- [ ] Registrar productos
- [ ] Visualizar inventario
- [ ] Actualizar cantidades
- [ ] Control de stock bajo
- [ ] Alertas de vencimiento
